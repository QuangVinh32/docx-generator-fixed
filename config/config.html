Cấu hình form HTML ↔ DOCX

Mỗi form HTML sẽ kết nối tới một file DOCX. Đưa file HTML vào thư mục forms, file Word vào templates, sau đó chọn cặp file ở đây và lưu.

Tên thuộc tính name của input trong HTML phải trùng với biến trong DOCX. Ví dụ name="patientName" kết nối với {patientName}.
